# GOI17 Tap

## How do I install these formulae?

`brew install goi17/tap/<formula>`

Or `brew tap goi17/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "goi17/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
